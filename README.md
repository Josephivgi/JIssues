# JIssues

JIssues is a Windows app where AI agents find security, speed and code issues in your projects, score each one and say if it is worth fixing.

This repo holds the JIssues releases. Download `JIssues-Setup.exe` from the [latest release](https://github.com/Josephivgi/JIssues/releases/latest).

JIssues checks this repo for updates: Settings > Updates downloads a new release's setup, checks its SHA-256 and installs it when you press Install and restart.
